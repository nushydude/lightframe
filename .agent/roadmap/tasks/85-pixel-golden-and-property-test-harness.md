## Goal

Provide deterministic pixel/golden/property helpers for decode, colour, preview, histogram, and export tasks while allowing documented platform tolerances.

## Current Code Context and source evidence

Astra requires pixel goldens and property infrastructure; synthetic screenshots do not prove native codecs. Existing Vitest/Rust tests are the integration homes.

Verify all paths against the fresh `origin/main` when the task is selected. Existing code is partial evidence and may have moved; do not treat a task plan or the Astra review as proof that implementation is complete.

## Scope and constraints

Goldens are tied to fixture hash, algorithm/version, colour policy, platform, and tolerance. Avoid unstable screenshot assertions and giant allocations. Missing required fixtures fail. Test harness must not hide production errors.

## Implementation steps

- Define golden metadata schema and comparison modes for exact, per-channel tolerance, geometry, and histogram metrics.
- Add Rust/TypeScript helpers for bounded decode/property generation and readable mismatch artifacts.
- Register corpus fixture IDs and fail on missing/changed inputs.
- Add seed/version logging and deterministic random generation.
- Add deterministic harness self-tests for manifest/hash metadata, exact/tolerance comparison, bounded property seeds, missing-fixture failure, and mismatch artifact generation.
- Exercise existing baseline behavior only: the current JPEG generator and preview/tile tests in `src-tauri/src/commands/mod.rs` (`make_test_jpeg`, `test_get_preview_image_blocking_respects_max_dimension`, and `test_get_image_tile_blocking_writes_expected_jpeg_tile`), synthetic RAW-preview byte containers and colour buffers generated by the harness, and current export tests (`test_save_scaled_copy_blocking_writes_new_image_with_expected_dimensions` plus rejection cases) in the same module.
- Keep future feature goldens with their owning tasks; this harness task must finish from tasks 84 and 85 alone and does not require implementing tasks 68, 71, or 72.
- Document when a golden is evidence versus a benchmark, and how reviewers update it.
